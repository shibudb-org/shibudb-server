# ShibuDB Changelog

## Version History

### 1.1.0 - 2026-08-04
- Added HashMap index for key-value space
- Added dump and restore functionality

### 1.0.9 - 2026-07-04
- Fixed CLI parser
- Fixed bug in WAL causing inconsistent replays
- Improved performance

### 1.0.8 - 2026-06-13
- Added new flat index with meta filters
- Added list-users command for admin users

### 1.0.7 - 2026-04-14
- Added data file segmentation for vector and key value engine
- Added command to rebuild index for a space

### 1.0.6 - 2026-04-01
- Added more connection details
- Optimised space manager for huge number of active spaces
- Added auth token in HTTP management APIs
- Added cli line editing support

### 1.0.5 - 2026-03-23
- Fixed data paths
- Fixed cli commands
- Added default ports
- Fixed connection limit usage

### 1.0.4 - 2026-03-18
- Added argument based login for cli

### 1.0.3 - 2026-03-18
- Fixed the hardcoded paths

### 1.0.2 - 2026-03-15
- Enabled deletion of vectors

### 1.0.1 - 2025-11-21
- Initial release
- Basic database functionality
- FAISS vector engine support
- Key-Value engine support
- Support for multiple platforms (Linux AMD64/ARM64, macOS ARM64)

## Current Version: 1.1.0
